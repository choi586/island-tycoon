# 3D 무인도 타이쿤 온라인

여러 사람이 동시에 접속해서, 한 사람이 섬 하나씩 가지고 키우는 3D 브라우저 게임이에요.

- 나무·바위를 캐서 다리를 놓고, 일꾼을 고용하고, 등대를 완공하세요.
- 접속한 사람마다 바다 위에 섬이 하나씩 생겨요. 👥 버튼 → "놀러 가기"로 친구 섬을 구경할 수 있어요.
- 감정 표현(👋❤️😂🎉👍😮)으로 인사할 수 있어요.
- 내 섬 진행 상황은 브라우저에 저장돼서 다음에 "이어하기"로 계속할 수 있어요.

## 실행

```bash
npm install
npm start   # http://localhost:3000
```

Render 무료 플랜(`render.yaml`)으로 배포돼요.
